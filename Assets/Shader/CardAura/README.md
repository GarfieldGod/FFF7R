# CardAura —— 卡牌辉芒（Unity 侧）

卡牌边缘**一直**向四周发散光芒，光条带扰动、缓慢流动，读作"这张卡可选 / 已被激活"。

和仓库里另外两个特效的分工：

| | 形态 | 什么时候用 |
|---|---|---|
| `GoldenFrame` | UI 金框，套在卡上，一圈边框在呼吸 | 需要"框住"某张卡/某个面板 |
| `BoardCellUpgrade` | 一次性 1.69 s 的升级流程（6 个部件 + 时间表） | 格子升级动画 |
| **`CardAura`** | **常驻状态**，不吃进度条，挂上一直发光 | 卡在手上/在场上"可选"、"已激活" |

整个文件夹拷进 Unity 的 `Assets/Shader/CardAura/` 即可，不用改名、不用挑文件。

```
CardAura/
├── CardAuraFX.cs       组件：建 quad、写参数、平滑开关
├── CardAuraFX.shader   光本身（程序化，零贴图）
├── Editor/
│   └── CardAuraMenu.cs 一键创建：GameObject / VFX / Card Aura
└── README.md           本文档
```

> 组件**不继承** `BoardCellUpgrade` 的 `CellFXPart`。那套是"吃 0..1 进度的部件"，由时间表驱动；
> 这个特效是常驻状态，语义不同，所以自成一个包 —— 只拷 `CardAura/` 这一个文件夹就能跑，
> 不依赖工程里任何别的东西。

## 1. 接入

**菜单**：`GameObject → VFX → Card Aura`
- 选中一张卡再执行 → 挂到它下面；没选中 → 放到世界原点。
- 会自动生成 `Materials/CardAura.mat`（`_ZTest = 4`，必须做深度测试，否则光会飘到棋子和卡牌前面）。

**位置**：菜单把 Y 抬到 `0.0265`（相对父级）。

- 父级原点在**棋盘面**（卡顶 0.020）→ 直接用，光正好浮在卡面上方 6.5 mm。
- 父级原点在**卡牌中面**（卡 Top 只有 0.00225）→ 把 Y 改成 `0.0085`。

太低会被卡牌整块挡掉（只剩边缘一条缝），太高会让光和卡面之间看出空隙。

**尺寸**：**Transform 恒为 (1, 1, 1)** —— 尺寸烘在网格顶点里（网格本身就建成 `cardW×(1+2·padding)` 那么大），
不是 1×1 的 quad 再靠 scale 拉。所以 1,1,1 就是正确比例，改大小只改 `cardSize` / `padding`（网格会就地改顶点）。
父级缩放会整体等比放大，比例不会跑。

> 之前在 Transform 上会看到 `(0.544, 1, 0.748)` 这种非等比数，那是旧版"1×1 quad + scale"的做法，
> 想放大还得自己算比例。现在 scale 干净了：真想让光比卡牌更大，乘一个统一系数即可（但就不贴着卡了）。
> 场景里的旧实例会**自动迁移**：第一次刷新会把 scale 归 1、把尺寸写进网格。

**开关**：勾 `on`，或代码 `aura.SetOn(true)`（约 0.17 s 淡入）；要立刻到位用 `SnapOn()`。

```csharp
var aura = card.GetComponentInChildren<CardAuraFX>();
aura.SetOn(true);                       // 可选 / 已激活
aura.SetTint(new Color(1f, .85f, .45f)); // 换整套色相（金）
aura.level = 3;                          // 只提亮度
```

## 2. 光是怎么拼出来的

三层，全部在片元里算，没有一张贴图：

| 层 | 作用 | 参数 |
|---|---|---|
| **rim** 贴边亮线 | 压在卡牌轮廓上的细亮线，内外各透一点 → "卡边在发光" | `rimWidth` 0.022 / `rimGain` 0.55 |
| **halo** 贴边柔光 | 对称的一圈柔光，把卡从棋盘上"托"起来 | `haloGain` 0.32 |
| **rays** 外发光芒 | 从卡边往外的长条光，按角度分布，越远越淡 | `rayCount` / `reach` / `offset` / `startAlpha` / `falloff` / `turbulence` |

`rays` 的关键是三件事：

1. **角度场在噪声空间里绕圈采样。** `θ → dir = (cosθ, sinθ)`，再把 `dir × (rayCount/2π)` 丢进 2D 值噪声。
   绕一圈正好跨过 `rayCount` 个噪声格，而且是 **2π 天然周期** —— θ = ±π 那根接缝上不会有硬线。
   *（拿 `atan2` 的结果直接喂 1D 噪声，就一定会在 −X 轴切出一条笔直的缝。任何"放射状"特效都必须用 `dir` 采样。）*
2. **域扭曲**（`turbulence`）把**采样点本身**推歪。所以要"扰乱"要动坐标，只调亮度是调不出来的。
3. **每条光芒长短不一**（`lenVar`，另一层低频噪声）。不加这个，所有光芒会停在同一半径上，看起来像个"壳"。
4. **角位置随半径漂移 → 光条是曲线。** 取 `θ_eff = θ + bend(r)`，`bend` 用两层噪声、幅度分别 ∝ r 和 r²：

   ```
   bend = _Bend · (d/unit) · N₁ + _BendS · (d/unit)² · N₂
   ```

   光条的位置本来由噪声等值线 `n(θ)` 决定；把 θ 换成 θ_eff 之后，同一条光在不同半径处对应不同角度，
   走出来的就是曲线而不是射线。`_Bend` 是"整根往一侧甩"，`_BendS` 是"远处翻回来"（S 形）。
   **两个都为 0 就退回直射线**，所以这是纯增量，没有破坏原有效果。
   *（这条也是"曲线光不必用序列帧"的证据：只多 2 次噪声采样，O(1) 成本。）*
5. **边缘不规则度**（`edgeIrregular`）管"光的外沿长什么样"，管两件事：

   | 值 | 长度（`lenVar`）| 末端暗缝 | 读起来 |
   |---|---|---|---|
   | `1`（默认）| 每条自己长短（0.55–1.45 倍）| 保留 | 野生的光芒，末端毛糙 |
   | `0` | 全部拉回 1.0 | 填平 | 外沿 = 卡牌边框的**等距外扩**，完全同形 |

   - **长度那一半**：光的长度量的就是卡牌 **SDF 距离**，所以只要所有光条都停在同一个距离，
     末端自然落成一条与卡牌轮廓等距的圆角矩形。换成极坐标半径就不是了 ——
     同样的半径在角上比边上远出去，外沿会变成一个圆角放大的"盾形"。
   - **暗缝那一半**：只统一长度不够。光条之间本来就有缝，缝里照样没光，
     外沿看上去还是一圈碎齿。所以按 `(1 − edgeIrregular)` 把**末端那一段**的角向起伏
     平掉（趋向 `streak × fl` 的角向均值 0.46，只抹平、不额外提亮），
     整圈亮度同步衰减到 0，可见的边界才是一条连续的线。
   - 平掉的只是 `t01` 后半段（`smoothstep(0.38, 1.0, t01)`），内圈的光条形状不动；
     `edgeIrregular = 1` 时这两项都不生效，和加参数之前逐像素一致。

径向分布：`d` 是到卡牌轮廓的有符号距离（SDF），所以**四条边的光长得一样长**
（不是先到短边再到长边那种歪的）。`d` 先减 `offset` 再除以 `(r2 − offset)` 得到 `t01 ∈ [0,1]`：

```
radial = (1 − t01)^falloff · lerp(startAlpha, 1, smoothstep(0, 0.45, t01))
```

- `offset` 决定**从哪儿开始有光**（< offset 只有 rim / halo），
- `startAlpha` 决定**起点有多亮**（1 = 贴边一道亮边，0.6 = 薄雾，0.3 = 从近乎透明亮起来），
- `falloff` 管**衰减得多快**。

默认 `reach 0.20 / offset 0 / startAlpha 0.60`：卡边外一小层（约 6.4 cm），不糊。
想回到"大片流动光条"那版，`padding 0.60 / reach 0.40 / startAlpha 1.0` 即可。

## 3. 参数表

**材质**（`Materials/CardAura.mat`，整套皮肤共享 —— 改这里换全部卡的配色）

| 属性 | 默认 | 说明 |
|---|---|---|
| `光芒颜色` | `(0.34, 0.74, 1.00)` | 深蓝白。再浅会被加色叠成纯白 |
| `光芒亮度` | 1.00 | 是整个 mask 的乘数。**先调这个，别先调颜色** |

**组件**（每个实例独立，不进材质）

| 字段 | 默认 | 说明 |
|---|---|---|
| `cardSize` | 0.32 × 0.44 | 卡牌尺寸（米），和 `CellFXShape` 同一套 |
| `cornerRadius` | 0.0174 | 卡牌圆角 |
| `padding` | 0.30 | quad 比卡牌每边大多少（× 短边）。**同时限制 `reach` 上限**（见排障）|
| `rayCount` | 30 | 一圈多少条光芒。短边上约 10 条 |
| `reach` | 0.20 | 发散多远（× 卡牌短边）。0.20 ≈ 6.4 cm |
| `offset` | 0 | **起点离卡边多远才起光**（× 短边）。0 = 贴边；0.06 ≈ 离边 2 cm（中间一圈空）|
| `startAlpha` | 0.60 | **起点强度**。1 = 起点最亮（贴边一道亮边）；0.6 = 薄雾；0.3 = 从近乎透明亮起来 |
| `edgeIrregular` | 1.0 | **边缘不规则度**。1 = 每条光长短不一、末端毛糙（野生光芒）；0 = 光的外沿变成与卡牌边框**完全同形**的圆角矩形（等距外扩 `reach`）|
| `turbulence` | 0.45 | 扰动强度（推歪采样点，让光条断/粗细不匀）。0 = 均匀放射（假）|
| `bend` | 1.6 | **弯曲的量**（弧度 / 卡牌短边，∝ 距离）。0 = 直射线 |
| `bendS` | 1.0 | **S 形弯曲**（∝ 距离²，远处翻回来）。0 = 只单侧弯（C 形）|
| `flow` | 1.0 | 流动速度 |
| `spin` | 5 | 整圈缓慢旋转（度/秒）。0 = 不转 |
| `falloff` | 1.05 | 越大越"贴边"，光收得越快 |
| `rimWidth` / `rimGain` | 0.022 / 0.55 | 贴边亮线的粗细 / 亮度。`rimGain = 0` 就不要这圈线 |
| `haloGain` | 0.32 | 贴边柔光 |
| `on` / `fadeSpeed` | true / 6 | 开关 + 淡入淡出速度 |

## 4. 四个必须知道的点

① **时间不吃进度条。** `_Time.y` 自己走，所以编辑器里一挂上就在动、暂停就停、`Time.timeScale` 也跟着。
不要给它接 `Animator` 或时间表 —— 它是"状态"，不是"动画片段"。

② **`_On = 0` 时渲染器直接关掉。** 不留一层全黑的全屏 quad 在场景里，也不会出现在 frame debugger 里。

③ **`quad 边上硬压到 0`**（`m *= ef.x * ef.y`，只在最后 0.12 个卡牌短边内起作用）。
辉光往外漏到 quad 边界会切出一条直边 —— 沿哪条边看都是个方框，非常明显。这条和 `reach` 的钳制是双保险。

④ **Transform 是 (1,1,1)，尺寸在网格里。** 网格按 `cardSize × (1+2·padding)` 直接建成那么大，
所以 1,1,1 = 正确比例；改尺寸走 `cardSize` / `padding`，组件会**就地改顶点**（不换 MeshFilter 引用，
因此不触发 `OnMeshFilterChanged`，也就不会在导入/校验阶段报 SendMessage）。
旧版把尺寸写在 `localScale` 上，场景里的旧实例第一次刷新时会自动归 1 并把尺寸写进网格。

## 6. 排障

| 症状 | 原因 |
|---|---|
| 完全看不到 | ① Y 低于卡牌顶面，被卡整块挡掉；② 材质的 `_ZTest` 不是 4；③ `on` 没勾 |
| 光芒比预期短 | `padding` 太小 —— `reach` 被钳到 `(quad − 卡) × 0.92`，这是为了保证不在 quad 边界处被切断。想更长就把 `padding` 调大 |
| 光糊得太开、太夸张 | 三个旋钮按顺序收：① `reach`（0.20 → 0.14）；② `startAlpha`（0.60 → 0.35，贴边那截变透）；③ `padding` 跟着 `reach` 一起收（不然中间一圈空）|
| 卡边和光之间有一圈黑缝 | `offset` 不为 0，而 `padding` 又压得太小。要么把 `offset` 归 0，要么把 `padding` 加到 `offset + reach` 之上 |
| 光条到某处突然"没了" | `offset` 太大，`reach × lenVar` 已经不到 `offset`，只剩一条窄带。把 `reach` 提到 `offset` 的 2 倍以上 |
| 光芒像一圈"毛边"/刺猬 | `rayCount` 太大（细碎）或 `turbulence` 太高（碎成点）。先降到 30 / 0.35 |
| 光的外沿毛毛躁躁，想要"顺着卡框走" | 降 `edgeIrregular`（1 → 0）。0 时外沿就是卡牌轮廓等距外扩出去的圆角矩形，长度和暗缝一起收干净 |
| 外沿太死板、像描了一圈边 | `edgeIrregular` 太低。0.3–0.5 之间还有起伏但整体跟卡框平行，通常最耐看 |
| 想要光线更弯 / 更"被吹动" | 加 `bend`（一次项，整根往一侧甩）。1.6 → 3.0 就很明显了；到 6 会绕到隔壁光条上 |
| 光线弯得像"钩子"停在半路 | `bendS` 太大（二次项在远处把光翻回来）。降到 0.5 以下，或直接设 0 只留 `bend` |
| 像一块均匀发光的大饼，没有光条 | `turbulence` 太低 + `streak` 的底色分量占比高。把 `turbulence` 提到 0.6 以上 |
| 整片发白，看不出蓝色 | 加色叠加超 1 了。降材质 `光芒亮度`（1.0 → 0.7），或把 `光芒颜色` 的 R 再压（0.34 → 0.2）|
| 光跟着卡一起"抖" | 卡在动，光也在动 —— 正常。要稳住就把父级的位移动画挪到子物体上 |
| 看到方形硬边 | `padding` 被改得很大而 `haloGain` 又很高，辉光摸到了 quad 边缘。`ef` 那条硬压会兜住，但会在框边形成一圈暗环；把 `padding` 收回来 |

## 7. 为什么不做成 PNG 序列帧

这个特效"每帧都不一样"，看上去很像该烘图集，但**不该**：

- **形状是卡牌轮廓决定的。** 卡牌 8:11 + 圆角，换成别的尺寸/别的卡面比例（棋盘上、手牌区、UI 里），
  图集就得重烘一套；SDF 算的永远贴合。
- **角向细节是高频的。** 一圈 30 条光芒，图集要 1024 才不糊；而且动画时相邻帧的光条位置对不齐，
  会看出"闪"（时间走样）。程序化每帧解析求值，不会有这个。
- **不能重复。** 要"一直发散且看不出循环"，图集得烘几百帧；这里三层噪声各自漂移，
  实测 t = 0 与 t = 6 s 的相关系数 −0.39，肉眼看不出周期。
- **改一个参数就要重烘。** 条数、扰动、速度、颜色、等级，全是运行时参数。

**"光线要弯"同样不需要图集。** 弯不弯取决于"光条的角位置是否随半径变化"，加一个 `bend(r)`
就够（2 次噪声采样）；烘一套曲线光的图集反而更难 —— 曲线和卡牌边缘的贴合关系、
每条曲线各不相同的长度，全都是每帧重算的。

图集的正当用途是"**整体轮廓**逐帧有机变形"（火焰的尖端、烟雾的卷），这里轮廓永远是卡牌的边，
变的只是密度和亮度 —— 属于"域内噪声调制"，正好是程序化的强项。

真要做手绘感更强的干扰，也不必烘整张效果图：把 shader 里 `N()` 换成采样一张**无缝循环噪声图**
（`tex2D(_NoiseTex, np / tile)`），图形由美术画、节奏仍由参数控。这是成本最低的折中。
