Test Case Editor

如何使用

1. 创建Step
点击左侧列表底部的 + 按钮新增一个矩阵状态，新状态继承上一个状态。

2. 编辑矩阵
点击矩形切换背景色（灰/绿/红），左上角 +/− 按钮切换模式。
− 模式：点击圆点切换点数（1~3）。
+ 模式：右上角输入数字，下方输入卡牌名。

3. 自动生成
点击 生成 按钮，自动对比上一个状态，填充输入者、卡牌和坐标。绿色→Player，红色→Rival。

4. 手动填写
也可直接在面板中输入，或点击矩阵下方坐标标签快速填入坐标。

5. 导出
导出JSON：保存矩阵数据为 .json。
导出用例：生成 C# 测试用例 .cs 文件。

6. 导入
导入JSON/导入用例：从已有文件恢复所有矩阵状态。
